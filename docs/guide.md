# AGENTS.md — PVHAI Accountant System

## Project Overview

Develop a professional desktop-style accounting application for Parkplace Village Homeowners Association Inc. (PVHAI).

## Technology Stack

### Frontend
- React
- JavaScript (not TypeScript)
- Vite
- Tailwind CSS v4
- Lucide React

### Backend
- NestJS
- MySQL
- TypeORM

Keep the frontend and backend separate.

## Development Rules

1. Use JavaScript for React components.
2. Use functional React components.
3. Use Tailwind CSS v4 for styling.
4. Use Lucide React for icons.
5. Keep code clean and reusable.
6. Avoid unnecessary dependencies.
7. Inspect existing files before modifying them.
8. Do not modify the backend unless explicitly instructed.
9. Do not connect to the production database or VPS.
10. Do not invent PVHAI branding assets or financial information.

## Current Task: Login UI Only

Create a professional login screen for the PVHAI Accountant System.

### Design Requirements

- Modern, clean, professional accounting-system appearance.
- PVHAI branding and application name.
- Username or email input.
- Password input.
- Show/hide password control.
- Remember me checkbox.
- Forgot password link (UI only).
- Sign In button.
- Clear input labels and icons where appropriate.
- Proper spacing, typography, and visual hierarchy.
- Responsive layout.
- Attractive background and login panel.
- Professional color palette suitable for an HOA accounting application.

### Functional Requirements

- Username/email and password fields must accept input.
- Password visibility toggle must work.
- Remember me checkbox must work.
- Sign In button can display a simple demonstration response.
- No actual authentication is required yet.

## Restrictions

For this task:

- Work only on the frontend.
- Do not create a dashboard.
- Do not create a sidebar or navigation modules.
- Do not implement backend authentication.
- Do not connect to MySQL.
- Do not create database tables.
- Do not install additional packages unless absolutely necessary.
- Use the existing project configuration.

## Completion

After implementation:

1. Verify the login screen renders.
2. Verify the password visibility toggle.
3. Verify the input fields and checkbox.
4. Check for compilation errors.
5. Summarize the files created and modified.

Stop after completing the Login UI. Wait for further instructions.
